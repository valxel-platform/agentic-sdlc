Valxel SDLC: architecture diagram

The tool runs in your environment, on one cloud: AWS, Google Cloud or Azure. One image runs the API and the workflows; agents work in sandboxed sessions that reach only the LLM gateway and the egress proxy; a separate provisioning worker holds the repo admin rights. Products deploy through OpenChoreo, or with Docker Compose on VMs in lite mode.
